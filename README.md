# java-racingcar-precourse
## 자동차 경주 기능 목록

### 입력 기능 구현

- [x] 자동차 이름 입력 기능

    - 사용자에게 "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 메시지를 출력한다.

    - 쉼표(,)로 구분된 자동차 이름 문자열을 입력받는다.

- [x] 시도 횟수 입력 기능

    - 사용자에게 "시도할 횟수는 몇 회인가요?" 메시지를 출력한다.

    - 시도할 횟수 문자열을 입력받는다.

### 유효성 검증 및 예외 처리 기능 구현

- [x] 자동차 이름 입력 형식 검증 기능

    - 입력받은 자동차 이름들이 쉼표(,)로 끝나는지 검증하고 예외를 발생시킨다.

- [x] 자동차 이름 길이 검증 기능

    - 각 자동차 이름이 5자 이하인지 검증하고, 초과 시 IllegalArgumentException을 발생시킨다.

- [x] 시도 횟수 검증 기능

    - 시도할 횟수가 숫자인지 검증하고, 숫자가 아닐 경우 IllegalArgumentException을 발생시킨다.

    - 시도할 횟수가 1 이상인지 검증하고, 1 미만일 경우 IllegalArgumentException을 발생시킨다.

### 핵심 로직 (자동차 경주 기능) 구현

- [x] 자동차 객체 생성 기능

    - 입력받은 자동차 이름 문자열을 쉼표(,) 기준으로 분리하여 Car 객체 리스트를 생성한다.

- [x] 전진 판단 기능

    - 0에서 9 사이의 무작위 값을 생성한다. (camp.nextstep.edu.missionutils.Randoms 사용)

    - 무작위 값이 4 이상일 경우 자동차를 전진(-)시킨다.

- [x] 경주 진행 기능

    - 입력된 시도 횟수(라운드)만큼 모든 자동차의 전진/멈춤 로직을 반복 실행한다.

- [x] 우승자 판별 기능

    - 모든 시도 완료 후, 가장 멀리 전진한 자동차를 우승자로 판별한다.

    - 우승자가 여러 명일 경우 공동 우승자로 처리한다.

### 출력 기능 구현

- [x] 결과 출력 기능

    - "실행 결과" 문자열을 출력한다.

    - 각 라운드별로 모든 자동차의 이름과 현재 전진 상태를 출력한다.

      - 예: pobi : --


- [ ] 최종 우승자 출력 기능

    - "최종 우승자 : " 접두사를 붙여 출력한다.

    - 공동 우승자가 있을 경우 쉼표(,)로 구분하여 출력한다.

        - 예: 최종 우승자 : pobi, jun
